# Brand

- `icon.svg`: the game icon (source). Edit this, then run `python tools/render_icon.py`.
- `icon-512.png`: Telegram bot profile picture (@BotFather → /setuserpic)
- `icon-192.png`, `icon-32.png`: browser tab and site icon
- `icon-180.png`: iPhone home-screen icon
- `banner-640x360.png`: wide cover with the title, used as the link preview image when the game's address is shared
