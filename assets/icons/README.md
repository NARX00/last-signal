# Icons

Images for weapons, systems and powers on upgrade cards, slots and power buttons. Name each file after the id in
`data/weapons.json`, `data/systems.json` or `data/powers.json`, e.g. `bolt.png`, `might.png`, `blink.svg`.
Square, about 64 px, under 50 KB. Anything without an icon keeps its glyph. See `docs/CONTENT.md`.
